# TerraFlux: Earth's thermal story, harmonized

An independent scientific web app for exploring Earth's fire activity through harmonized MODIS and VIIRS satellite observations from NASA FIRMS. Built by Team Emberline for the NASA Space Apps Challenge 2026 ("Harmonization of MODIS and VIIRS Hot Spots").

DATA SOURCE: NASA FIRMS  
BUILT FOR: NASA SPACE APPS CHALLENGE 2026  
NOT AN OFFICIAL NASA PRODUCT
